# hao-backprop-test

A simple Hello World HTTP server built with Python and Flask. Test project for backprop integration.

## Prerequisites

- Python 3.13 or higher
- pip (Python package manager)

## Installation

Create and activate a virtual environment (optional but recommended):

```bash
python -m venv venv
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Usage

Start the server:

```bash
python app.py
```

The server starts on `http://127.0.0.1:3000/` and responds with `Hello, World!` to all requests.

## Technology Stack

- Python 3.13
- Flask 3.1.3
